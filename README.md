# Anchors

ROFLY(로블록스FLY) 게임 저장소. [Rojo](https://rojo.space)로 VS Code에서 짠 코드를 Roblox Studio에 실시간 동기화합니다.

## 자료

- 기획서(온라인, 최신본): https://claude.ai/artifact/BPTtwcD7fyrYZ7Ac6vHFE4
- `docs/concept-images`: 챕터별 콘셉트 이미지 (`old-v1`은 이전 버전)
- `docs/diagrams`: 로켓 부품 그리드 다이어그램
- `docs/planets`: 다음 행성 슬롯의 행성 썸네일 원본 (ChatGPT로 생성, 512px 투명 PNG). Roblox에 올린 이미지 ID는 `src/shared/Planets.luau` 의 `Thumb` (그림을 바꾸면 다시 올리고 ID를 바꿈)

## 폴더 구조

| 폴더 | Studio 위치 | 용도 |
|---|---|---|
| `src/server` | ServerScriptService › Server | 서버 코드 |
| `src/client` | StarterPlayer › StarterPlayerScripts › Client | 클라이언트 코드 |
| `src/shared` | ReplicatedStorage › Shared | 서버·클라 공용 모듈 |

- 파일 이름 규칙: `이름.server.luau` = Script, `이름.client.luau` = LocalScript, `이름.luau` = ModuleScript
- **코드는 VS Code에서만 수정.** Studio에서 고친 코드는 파일에 안 남습니다.
- 맵·모델·UI 배치는 Studio에서 작업하고 `File › Publish to Roblox`로 저장합니다.

## 외형 모델 (GPT가 만든 코드)

로켓 겉면·발사장·행성 소품은 GPT 최신 모델이 새로 디자인한 'BREAKLINE'입니다. 디자인 문서는 `docs/exterior/DESIGN.md`(콘셉트 그림 `docs/exterior/concepts/`), 파트 수·치수는 `docs/exterior/NOTES.md`. 아래 모듈이 ▶ Play 때 파트로 만듭니다.

| 파일 | 만드는 것 | 폰 사양 한도 |
|---|---|---|
| `src/server/RocketShell.luau` | 구조선 CITADEL 겉면 (12면 강철 선체·추진 리브·코·엔진 종) | 파트 180개, 열 빛(`Heat` 속성) 16개 |
| `src/server/LaunchPad.luau` | 발사장 LAST GATE (발사대·두 교각 관문과 탑승 팔·정비 데크·운영동·광장 표시) | 파트 90개, 빛 2개 |
| `src/client/PlanetProps.luau` | 행성 소품 11종·지형지물 8종 (행성마다 다른 바이옴 모양) | 소품 5개(평균 3.5), 지형지물 16개, 행성마다 500개 |

- 모든 외형은 폰에서도 쉽게 돌아가야 합니다. 위 한도를 넘기지 않습니다.
- 다른 코드가 이름으로 찾는 파트: `LowerHull`·`UpperHull`·`NoseTip`, `RimLight`·`ControlWindow`·`MastLamp`(안에 SpotLight)·`Mount`·`TowerArm`(연료 탱크를 만들면 `FuelTank`), 소품의 `Pool`·`Cap`·`Crystal`.
- 모양을 바꿀 때는 손으로 고치지 않고 GPT에게 다시 맡깁니다.

## 처음 세팅 (맥, 1회)

1. **Roblox Studio**: [create.roblox.com](https://create.roblox.com)에서 Studio 다운로드 → 설치 → 로그인
2. **VS Code**: [code.visualstudio.com](https://code.visualstudio.com)에서 다운로드 → 앱을 `응용 프로그램` 폴더로 이동
3. **Git**: 터미널 앱 열고 실행 (이미 설치됐다고 나오면 통과)
   ```sh
   xcode-select --install
   ```
4. **Rokit** (Rojo 설치 도구): 실행 후 터미널 창 닫고 새로 열기
   ```sh
   curl -sSf https://raw.githubusercontent.com/rojo-rbx/rokit/main/scripts/install.sh | bash
   ```
5. **프로젝트 받기 + Rojo 설치**: Studio는 끈 상태에서 (작업 폴더는 `~/ROFLY`)
   ```sh
   git clone https://github.com/mantenine-lgtm/Anchors.git ~/ROFLY
   cd ~/ROFLY
   rokit install          # Rojo 설치 (물어보면 y)
   mkdir -p ~/Documents/Roblox/Plugins
   rojo plugin install    # Studio용 Rojo 플러그인 설치
   ```
6. **VS Code 확장**: VS Code `File › Open Folder` → `ROFLY` 폴더 열기 → 오른쪽 아래 권장 확장 알림에서 설치
   (안 뜨면 확장 탭에서 `Luau Language Server` 검색 → 설치. 자동완성·오류 표시용)

## 연결 확인

1. VS Code `Terminal › New Terminal` → `rojo serve`
2. Studio 실행 → Baseplate 새로 만들기 → 상단 `Plugins` 탭 → `Rojo` → `Connect` (접근 허용 물으면 허용)
   - **▶ Play 전, 편집 상태에서 연결해야 합니다.** 플레이 중에 누르면 `Http requests can only be executed by game server` 오류가 납니다.
   - 연결되면 Explorer의 ServerScriptService 안에 `Server › Main`이 생깁니다.
3. ▶ Play → Output 창(안 보이면 `Script` 탭에서 열기)에 아래 두 줄이 나오면 성공
   ```
   [ROFLY] 데모 1 서버 시작
   [ROFLY] 데모 1 클라이언트 시작
   ```
4. `File › Publish to Roblox`로 게임 게시 → 다음부터 이 게임을 열어서 작업

## 데모 1 해 보기 (비행이 재밌는가)

발사장·로켓·행성은 코드가 ▶ Play 때 만듭니다. Studio 맵에 따로 놓을 것은 없습니다.

1. `rojo serve` → Studio에서 `Rojo › Connect` → ▶ Play
2. 한 판 흐름: 탑승(30초, 모두 타면 5초) → 조립(45초, 탄 사람이 모두 다 꽂으면 5초 뒤) → 카운트다운(10초) → 비행 → 정산(25초) → 다시 탑승
   - 발사 행성: 판마다 다른 둥근 행성(용암·얼음·정글·사막·수정·바다)에서 발사합니다. 땅·지형지물·하늘빛이 바뀌고, 발사하면 행성이 점점 멀어지며 작은 공이 됩니다(선실 창과 바깥 시점 모두). 행성 목록은 `src/shared/Planets.luau`
   - 선실: 탑승하면 선실 바닥에 서고, 그 뒤로 판이 끝날 때까지 선실 안을 걸어다닙니다(의자 없음). 선실은 4면입니다:
     앞뒤 두 면은 외창, 한쪽 벽은 진행도 전광판, 반대쪽 벽은 부품 장착판(누가 어느 칸에 꽂았는지. 내 칸은 분홍 굵은 테두리와 분홍 '나' 딱지,
     남의 칸은 흐리게)과 그 아래 `내 부품` 판입니다.
   - 내 부품: 부품 6종(종류별 1개)마다 레벨(만렙 10,000)과 경험치가 있고, 처음엔 모두 일반 Lv1입니다. 비행하는 동안 1초마다
     부품 하나에 경험치 10,000씩 쌓입니다(탄 사람만. 봇·관전자는 없음). 다음 레벨까지 경험치 = 내림(희귀도 계수 × (레벨 + 500)² / 500),
     희귀도 계수는 일반 1·희귀 2·영웅 3·전설 4라서 초반엔 잘 오르고 갈수록 힘들어집니다(첫 판에 Lv700 안팎, 만렙까지 일반 약 500판·전설 약 2,000판).
     `내 부품` 판(장착판 아래)에서 비행 중 경험치 막대가 차고, 레벨이 오를 때마다 그 부품 자리에서 폭죽이 터지며 `+N Lv`가 뜹니다.
     오른 레벨은 다음 판부터 파워에 들어갑니다(레벨 배율 10^((레벨−1)/9999): Lv1 ×1, Lv1,000 ×1.26, Lv5,000 ×3.16, Lv10,000 ×10).
     조립 화면 칸에도 그 사람 부품 레벨이 보입니다. 서버가 켜져 있는 동안만 기억합니다(나갔다 들어와도 이어짐, 저장은 아직 없음).
     수치는 `Config.Progress`
     행성은 비행 중에 앞쪽 외창(발사장 리스폰 지점 쪽) 너머에 보입니다. 배치 수치는 `Config.World`, 자리 계산은 `src/shared/Cabin.luau`
   - 전광판(진행도) 아래쪽 추격 화면: 로켓이 왼쪽 행성에서 오른쪽 `폭발권 밖`으로 가고, 붉은 충격파 면이 뒤따라옵니다. 면과 로켓 꼬리 사이 간격은 충격파 도달 예상 시간(30초 이상이면 가장 멂)이라 미션에 성공하면 면이 밀려나고, 위기 때는 바짝 붙습니다. 면이 꼬리에 닿으면 로켓이 터지고 비행이 끝납니다. 노란 선은 이 서버의 최고 기록. 그림은 `src/client/ChaseView.luau`
   - 다음 행성 슬롯: 정산 15초 뒤 슬롯이 5초 돌다가 다음 판 행성에서 멈춥니다. 지금 행성은 빼고 나머지에서 확률대로 뽑으며, 칸마다 썸네일·이름·확률, 아래에 확률표가 나옵니다(10% 이하는 `희귀`). 확률은 `Planets.luau` 의 `Weight`(임시 값), 시간은 `Config.PlanetSlot`
   - 행성 분위기: 행성마다 빛 색·색감·빛 번짐·떠다니는 입자(불티와 재·눈·반딧불이·모래바람·반짝이·바다 안개)·빛나는 소품 불빛·발사장 불빛 색이 다릅니다. 발사해서 폭풍 구름층(3 km)에 들어가면 비행 연출로 돌아갑니다. 값은 `src/shared/PlanetMoods.luau`
   - 비행 연출: 대기권(100 km까지)에서는 빠를수록 코와 외창 바깥면이 빨갛게 달아오르고 화면이 흔들립니다. 별빛 줄기는 대기권을 벗어난 뒤에만 나옵니다(보통 장비는 대기권 안에서 끝나므로, 보려면 디버그 패널의 `장비` 버튼으로 `전설 Lv10,000`을 고릅니다. 다음 판부터). 수치는 `Config.Atmosphere`
   - 보유 코인: 오른쪽 위 티켓 칸 옆 `보유 코인` 칸에 늘 보입니다. 비행 중에는 날아간 거리만큼 코인이 날아 들어와 보유 코인이 오르고,
     칸 위쪽에 `이번 비행 +N`이 보입니다. 부스터를 쓰면 그 부스터 색 코인이 화면 가운데에서 터져 나와 칸으로 모이고,
     더 번 코인이 많을수록 코인 수·크기·글자·반짝임이 커집니다(적으면 작게). 비행이 끝나면 `이번 비행 +N`은 정산 코인과,
     보유 코인은 서버의 보유 코인과 같아집니다(정산 코인을 두 번 세지 않음). 수치는 `Config.CoinFx`
3. 조작
   - 탑승: 화면 아래 `탑승` 버튼
   - 부품 조립: 조립이 시작되면 조립 화면이 뜹니다. 부품 6종류마다 그리드가 있고, 테두리가 빛나는 그리드의
     빈 칸(+)을 눌러 종류마다 1개씩 꽂습니다. 이미 꽂은 종류는 다른 빈 칸을 누르면 옮겨집니다.
     `남은 부품 자동으로 꽂기` 버튼도 있고, 시간이 끝나면 못 꽂은 부품은 빈 칸에 자동으로 꽂힙니다
   - 조립 화면 끄기/켜기: `닫기 (B)` 버튼, 닫으면 화면 아래 `부품 조립 열기` 버튼, 또는 B 키(게임패드 Y)
   - 걷기: 선실 안에서 WASD(또는 방향키)와 스페이스(점프), 카메라는 오른쪽 마우스 끌기. 터치 기기는 기본 이동 스틱
   - 미션: 화면에 뜬 순서대로 방향키(또는 WASD)와 스페이스(점프). 미션이 뜨면 입력을 끝낼 때까지(또는 시간이 끝날 때까지)
     그 자리에 멈추고, 끝나면 다시 걸을 수 있습니다. 터치 기기는 그동안만 이동 스틱 대신 화면 버튼이 뜹니다
     (WASD가 안 먹으면 방향키를 쓰거나 한/영 키로 영문 입력 상태로 바꿉니다. 채팅을 치는 동안에는 미션 키가 눌리지 않습니다)
   - 선장 발사: 카운트다운이 0이 되는 순간 스페이스 또는 `발사!` 버튼 (안 누르면 자동 발사).
     선장에게는 조립이 끝나기 5초 전에 조립 화면에서 미리 알리고, 카운트다운 5초 전에 화면 테두리가 금색으로
     깜박이며 `발사 임박!`과 경보음이 나옵니다
   - 부스터: 비행 중 화면 왼쪽 메뉴의 버튼 6개(구원 연료·터보 엔진·중력 새총·웜홀·황금 항로·공명 코어). 누르면 바로 쓰고 티켓 1장이 듭니다.
     종류마다 한 비행에 로켓 전체에서 한 번(먼저 누른 사람)이고, 구원 연료는 위기(충격파 접근) 때만 켜집니다.
     버튼 아래 줄: `티켓 1`(쓸 수 있음) · `위기 때만` · `티켓 없음` · 남은 초(효과 중) · `적용 중`(황금 항로) · `사용됨`.
     PC는 버튼에 마우스를 올리면 효과 설명이 나옵니다. 처음 들어오면 티켓 3장(임시)이고, 디버그 패널의 `티켓 +1`로 더 받을 수 있습니다
   - 감사: 다른 사람(봇)이 부스터를 쓰면 뜨는 `고마워요!` 버튼
   - 시점: 오른쪽 위 `시점` 버튼으로 선실(기본 카메라가 내 캐릭터를 따라감) ↔ 바깥.
     카운트다운이 시작할 때는 선장을, 누가 부스터를 쓰면 그 사람을 선실 어디에 있든 잠깐 비춥니다
4. 혼자 하면 빈자리는 봇이 채웁니다(기본 10명).
5. 디버그 패널: 오른쪽 위 `디버그` 버튼 (Studio와 게임 주인에게만 보임)
   - 다음 단계로 넘기기, 티켓 +1, 코인 +1000, 내 부품 레벨 +1000(6개 모두, 폭죽도 터짐), 위기 구간으로 건너뛰기, 봇이 구원 연료 사용
   - 승무원 수·장비 바꾸기(다음 판부터), 봇 실력 바꾸기(다음 미션부터), 행성 바꾸기(바로), 지표 출력(Output 창)
   - 장비: 기본은 `각자 부품`(사람은 자기 부품 레벨, 봇은 일반 Lv1). 시험용 묶음 `일반 Lv1`·`희귀 Lv4,445`·`영웅 Lv4,445`·`전설 Lv10,000`은
     사람·봇 모두 같은 장비입니다
   - 선실 바닥은 100명이 서도 되게 잡았습니다. 판이 시작할 때 선장은 가운데, 나머지는 가운데에서 바깥쪽으로 퍼져 섭니다(봇은 바깥쪽).
6. 휴대폰 화면은 Studio `Test › Device`에서 기기를 골라 확인합니다.
7. 수치는 모두 `src/shared/Config.luau` 한 파일에 있습니다. 고치고 저장하면 다음 ▶ Play부터 반영됩니다.
8. 소리는 Roblox 내장 임시 소리입니다. 일부는 안 날 수 있습니다(Output에 경고만 뜸).
