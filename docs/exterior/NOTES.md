## RocketShell.luau · CITADEL

12면 강철 외장이 선실 양옆의 세로 용접선을 따라 위아래로 이어집니다. 넓은 추진 리브 네 곳을 Y=68 이하에 두고, 노즈는 뒤로 기울어진 한 점으로 모았습니다. 하부에는 밝은 금속 벨과 어두운 목 부분을 두 줄로 나눴습니다.

- **150 BaseParts**, 조명 0개입니다. `Heat` 16개는 `UpperHull` 1개에 0.30, `LeadingEdge` 2개에 0.50, `RakedNose` 아래쪽 6개에 0.63, 위쪽 6개에 0.84, `NoseTip` 1개에 1.00입니다.
- 기본 R=38에서 선실 위아래의 12면 외장 반경은 약 37.146~38.456스터드입니다. 선실 접점 Y=120과 Y=160의 반경은 정확히 38입니다. 리브를 포함한 최대 반경은 49.879스터드, 타워 방향 구역의 최대 반경은 38.456스터드입니다.
- `NoseTip` 최고점은 Y=279.982이며 모델의 직속 파트입니다. `EngineBell` 6개의 하단은 Y=4이고, 추진부 최대 반경은 26.392스터드입니다.
- 빌더가 반환하는 `LowerHull`이 `PrimaryPart`입니다. 반경을 36 이하로 낮추는 경우 기존 선실 계산에 맞게 `CabinRadius < HullRadius`와 `(CabinRadius + HullRadius) / 2 > PanelWallX + 1`을 만족하도록 설정합니다.

## LaunchPad.luau · LAST GATE

두 교각에 각각 폭 9.7스터드의 관통 슬롯과 X자 보강재를 넣었습니다. 정비 데크를 Y=58과 Y=147에 배치했고, 운영동의 밝은 외장과 서비스 베이 조명으로 출입구를 구분했습니다.

- **87 BaseParts**, **SpotLight 2개**입니다. `Plaza`와 `Spawn`을 포함하면 89파트입니다.
- 관문 최고점은 Y=194.35, 광장 시설 최대 반경은 146.780스터드, 스폰 중심과 가장 가까운 파트 사이 거리는 23스터드입니다.
- `Mount`의 윗면은 Y=4입니다. `TowerArm`의 중심은 Y=118이며 로켓과의 간격은 R=30·38·45에서 각각 1.0스터드입니다.
- 행성별 색상 대상은 `RimLight` 17개, `ControlWindow` 1개, `MastLamp` 2개와 각각의 SpotLight입니다.

## 검증

Roblox API 모형에서 이름과 파트 플래그, 로켓의 창과 타워 방향 외곽 한계, 엔진 벨 접지, 발사장 통로와 카메라 구역, 소품의 시드 재현성 및 파트 수를 확인했습니다. 반경 30~45와 여러 소품 배율을 검사했습니다. 이번 수정본의 게임 테스트와 실제 기기 렌더링은 통합 환경에서 확인할 수 있습니다.
